Execution Flow

sequenceDiagram
    participant User
    participant Agent as Paperclip Agent
    participant LLM as Gemini 2.5 Flash
    participant Planner
    participant Tools
    participant System

    User->>Agent: Natural Language Instruction
    Agent->>LLM: Analyze & Understand Intent
    LLM-->>Agent: Parsed Intent + Context
    
    Agent->>Planner: Decompose into Tasks
    Planner-->>Agent: Task Plan
    
    loop For Each Task
        Agent->>Tools: Select & Execute Tool
        Tools->>System: Perform Action
        System-->>Tools: Action Result
        Tools-->>Agent: Observation
        
        alt Error Detected
            Agent->>Agent: Error Recovery
            Agent->>Planner: Replan if Needed
        end
    end
    
    Agent->>LLM: Synthesize Results
    LLM-->>Agent: Final Response
    Agent-->>User: Complete Result + Feedback

Built with OpenHands Software Agent SDK + Gemini 2.5 Flash
